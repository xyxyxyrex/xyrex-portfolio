# Cléa project and scribble mark

The source project is `xyxyxyrex/clea` (private). Reviewed its README, package metadata, `src/style.css`, `src/App.tsx`, existing favicon, and evidence manifest using the authenticated repository owner account. The local checkout is `Desktop/sciel`.

The portfolio describes the implemented audio/MIDI visualizer: 60 selectable looks, local audio/MIDI/image inputs, seeded variations, composed layouts, and SVG print export. Its stack includes React, TypeScript, Tone.js, PixiJS, and Meyda. The card takes its dark olive surface, muted paper text, orange accent, and Arial wordmark styling from the source CSS. The private source has no public repository link or invented demo URL in the UI.

## Logo

`scribble-reference.png` is an unchanged copy of the supplied Desktop/Untitled.png sketch. The new editable mark retains its diagonal spine and overlapping scribble loops, with consistent rounded strokes and simplified negative space. This is native vector artwork, not an AI-generated bitmap or an automatic trace.

Files in `public/assets/projects/clea/`:

- `clea-mark.svg`: transparent charcoal vector master.
- `clea-mark-light.svg`: paper-colored version used on the dark project card.
- `clea-mark-512.png`: transparent raster copy of the vector master.
- `favicon.svg`: simplified small-size version on a rounded beige tile.
- `favicon.ico`: 16, 24, 32, 48, and 64px icon entries.
- `favicon-16.png`, `favicon-32.png`, `favicon-48.png`, `favicon-192.png`, `favicon-512.png`.
- `apple-touch-icon.png`: opaque 180px PNG.

SVG-to-PNG exports were rendered with resvg. The ICO was encoded with Pillow. The main symbol and actual-size 16/32/48px favicon previews were visually inspected. The icon files are supplied for reuse; this does not replace the portfolio's own favicon or change the private Cléa repository.
